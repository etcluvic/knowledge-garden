# Machine Learning

> Computational approaches that learn patterns from data rather than following explicit rules. Machine learning underpins contemporary AI systems and inherits assumptions about what counts as intelligence, whose data gets represented, and how knowledge can be decomposed into patterns extractable from large datasets.
